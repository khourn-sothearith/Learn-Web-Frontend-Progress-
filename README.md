# 🌐 ETEC Full Stack Web

This repository contains my learning progress, exercises, assignments,
learning materials, and practice projects from my **Full Stack Web Development**
course.

The main purpose of this repository is to document my learning journey from
the fundamentals of Front-End Web Development to JavaScript and practical
web projects.

## 📚 About This Repository

This repository contains my weekly learning progress and practical work.

I organized my work into different folders based on the topics and weeks I
studied.

The Frontend section includes:

- HTML
- CSS
- Bootstrap
- JavaScript
- DOM (Document Object Model)
- Web design practice
- Practical projects

This repository will continue to grow as I learn more about Full Stack Web
Development.
